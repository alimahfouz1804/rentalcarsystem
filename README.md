# Rental Car Management System

A console-based Rental Car Management System developed in C++ as a university project for the **Programming 1 course in 2025**.

## Features
- Add, update, and remove cars
- Register and update customers
- Display available cars
- Reserve, modify, and cancel reservations
- Search cars by model
- Calculate rental costs
- View transaction reports

## Technologies Used
- C++
- Arrays
- Functions
- Loops and conditional statements

## How to Run
1. Download the project.
2. Open the `.cpp` file in a C++ IDE.
3. Compile and run the program.
4. Follow the console menu instructions.

- **Course:** Programming 1
- **Year:** 2025

This project was developed in 2025 as part of the Programming 1 course to apply fundamental programming concepts through a practical car rental management system.
